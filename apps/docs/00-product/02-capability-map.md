# 功能说明

用简明语言说明**当前开放**的能力。需要机制与配置细节时，点「详情」进入对应技术文档。

> 下表与控制台默认可见能力对齐。未列出或标为「未开放」的能力，见文末 [功能边界](#功能边界)。

## 开放能力一览

| 能力 | 解决什么 | 谁常用 | 界面入口（示意） | 依赖 | 限制 / 注意 | 详情 |
| --- | --- | --- | --- | --- | --- | --- |
| 工作空间与成员 | 多团队隔离、按角色协作 | 管理员 | 设置 → 空间 / 成员 | 账号体系 | 四级角色：所有者 / 管理员 / 贡献者 / 访客 | [租户与认证](/03-features/01-tenant-auth) |
| 知识库 | 组织一批相关资料 | 知识维护者 | 侧栏 → 知识库 | 解析与模型就绪 | 先建库再上传 | [知识库](/03-features/02-knowledge-base) |
| 文档解析 | 把文件变成可检索文本 | 知识维护者 | 上传后自动进行 | 解析服务 | 扫描件依赖 OCR；复杂版式可能需人工改分块 | [文档解析](/03-features/03-document-parsing) |
| 分块与编辑 | 控制检索粒度与纠错 | 知识维护者 | 知识详情 → 分块 | — | 改分块后需重建索引 | [分块](/03-features/04-chunking) |
| 混合检索 | 提高召回与排序质量 | 管理员（选型） | 设置 → 向量 / 检索相关 | 向量库与模型 | 控制台默认可选引擎有限，见技术篇说明 | [检索引擎](/03-features/05-retrieval-engines) |
| 模型管理 | 接入对话 / 向量 / 重排等模型 | 管理员 | 设置 → 模型 | API Key 或本地推理 | 需按类型分别配置 | [模型管理](/03-features/06-models) |
| 智能体 | 按场景配置问答策略与工具 | 管理员、知识维护者 | 侧栏 → 智能体 | 模型 + 知识库 | 快速问答 vs 多步推理用途不同 | [Agent](/03-features/07-agent) |
| MCP | 接外部工具或对外暴露检索 | 集成方、研发 | 设置 → MCP | 网络与授权 | 生产环境注意审批与权限 | [MCP](/03-features/08-mcp) |
| 知识图谱 | 回答「谁和谁什么关系」类问题 | 知识密集场景 | 知识库配置中开启 | 图数据库与抽取模型 | 有成本，按需开启 | [知识图谱](/03-features/09-knowledge-graph) |
| 联网搜索 | 库内不足时查外部信息 | 需要时效信息的场景 | 智能体 / 设置中配置 | 搜索提供商 | 默认可选提供商有限 | [网络搜索](/03-features/11-web-search) |
| IM 机器人 | 在群聊里直接问知识库 | 全员 | 设置 → IM 集成 | 企微 / 飞书 / 钉钉应用 | **仅这三平台为当前开放** | [IM 集成](/03-features/12-im-integration) |
| 网页嵌入 | 官网 / 门户挂问答挂件 | 管理员、前端 | 设置 → 网页嵌入 | 发布渠道与域名 | 访客侧权限按渠道配置 | [网页嵌入](/03-features/13-embed-channel) |
| Wiki | 把资料整理成可导航百科 | 知识维护者 | 知识库 Wiki / Wiki 浏览 | LLM | 生成耗时与费用随资料量上升 | [Wiki](/03-features/14-wiki) |
| 评估 | 量化问答效果 | 管理员、质检 | 评估相关入口 | 测评集与模型 | 用于迭代，非日常问答必需 | [评估](/03-features/15-evaluation) |
| FAQ | 固定话术精确匹配 | 客服、运营 | FAQ 型知识库 | — | 适合政策类短答，与文档库可并存 | [FAQ](/03-features/17-faq) |
| 会话体验 | 多轮对话与引用展示 | 业务用户 | 对话页 | — | — | [会话体验](/03-features/18-chat-experience) |
| 存储 | 文件落盘位置 | 运维、管理员 | 设置 → 存储 | 对象存储或本地盘 | 默认可选：local / MinIO / OSS / COS | [存储后端](/03-features/19-storage-backends) |
| 平台管理 | 系统级租户与审计 | 系统管理员 | 平台管理相关 | 系统管理员身份 | 与空间内角色分层 | [平台管理](/03-features/20-platform-admin) |

## 功能边界

| 能力 | 说明 |
| --- | --- |
| 数据源自动同步 | 飞书云文档 / Notion / 语雀 / RSS 等定时同步 |
| 共享空间（组织） | 跨工作空间的组织共享 |
| 命令行 / Go SDK | 面向脚本与集成的客户端 |
| 小程序 / 桌面 / Chrome / Claw | 额外客户端形态 |
| 单机精简版 | 无 Docker 的精简运行形态 |

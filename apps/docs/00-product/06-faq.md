# 常见问题

常见使用问题的**现象与处理方向**；需要改配置或看日志时，请结合技术文档排查。

## 回答不准或答非所问

**可能原因**：资料未覆盖；分块切坏；绑错知识库；模型能力不足。

**建议**：

1. 看出处是否点到相关文档；完全无出处时先确认库内是否有该内容
2. 补文档或修订分块后再问
3. 确认对话使用的智能体绑定了正确知识库

技术参考：[知识库](/03-features/02-knowledge-base)、[分块](/03-features/04-chunking)、[Agent](/03-features/07-agent)。

## 文档一直「解析中」或失败

**可能原因**：文件损坏 / 格式不支持；解析服务异常；扫描件需 OCR 未就绪。

**建议**：

1. 换一份标准 PDF/Word 试传，区分「单个文件问题」还是「整体服务问题」
2. 检查文件是否加密、是否超大
3. 仍失败则记录文件名、时间与截图，交运维排查

技术参考：[文档解析](/03-features/03-document-parsing)。

## 提示无权限 / 看不到菜单

**可能原因**：角色为访客；不在当前空间；非系统管理员却进入了平台级功能。

**建议**：请空间管理员调整角色或邀请；确认左上角 / 空间切换在正确空间。

见 [角色与权限](./05-roles-delivery)。

## 模型不可用 / 问答报错

**可能原因**：密钥失效、额度用尽、服务地址不通、未选模型。

**建议**：管理员在「设置 → 模型」检查配置并试连；确认智能体已选择可用模型。

技术参考：[模型管理](/03-features/06-models)。

## IM 机器人不回复

**可能原因**：渠道未启用；凭据错误；未绑定智能体；回调未配好；当前平台不在开放列表。

**建议**：

1. 确认平台为**企业微信 / 飞书 / 钉钉**
2. 核对渠道启用状态与智能体绑定
3. 在测试群复现，保留消息时间供排查

技术参考：[IM 集成](/03-features/12-im-integration)。

## 网页嵌入不显示或不能问

**可能原因**：脚本未加载；渠道未发布；域名 / 鉴权配置不符。

**建议**：用浏览器开发者工具看脚本是否 404；核对嵌入配置与技术文档步骤。

技术参考：[网页嵌入](/03-features/13-embed-channel)。

## 能否接入 Notion / 自动同步网盘？

当前默认**未开放**数据源自动同步与共享空间等能力，见 [产品概述 · 功能边界](./01-overview#功能边界) 与 [功能说明 · 功能边界](./02-capability-map#功能边界)。

## 需要技术支持时请提供

- 发生时间、操作账号与空间名称
- 知识库 / 智能体名称
- 现象截图（可打码）
- 是否仅 Web 或仅 IM 出现

# 应用场景

用 3 条常见场景说明「怎么用、期望达到什么效果」。操作细节见 [操作指南](./04-user-guide)；机制见对应功能技术篇。

---

## 场景一：制度 / 手册问答

**背景**：公司有员工手册、报销制度、安全规范等 PDF/Word，员工经常问「能不能报」「流程是什么」。

**角色**：知识维护者建库；全员在 Web 或 IM 提问。

**建议步骤**：

1. 创建文档型知识库并上传制度文件（见 [操作指南 · 建库与上传](./04-user-guide#建库与上传资料)）
2. 确认解析完成，抽查关键条款分块是否正确
3. 配置对话与向量模型（见 [操作指南 · 配置模型](./04-user-guide#配置模型)）
4. 创建智能体并绑定该知识库
5. 用真实问题试问，检查出处是否点到正确章节
6. （可选）在企业微信 / 飞书 / 钉钉接入同一智能体

**效果预期**：

- [ ] 至少 10 个高频问题能答到正确条款
- [ ] 回答带可打开的出处
- [ ] 提问人可用访客或成员角色完成提问（按权限设计）

## 场景二：项目 / 售后知识库

**背景**：项目方案、故障案例、接口说明分散在多人手里，新人上手慢、重复答疑多。

**角色**：负责人组织资料；知识维护者维护库；一线查询。

**建议步骤**：

1. 按项目或产品线建库，约定命名与目录规范
2. 批量上传方案、纪要、案例；重要网页可用 URL 抓取
3. 对答错的片段做分块修订（不必整份重传）
4. （可选）开启 Wiki，生成可浏览的知识目录
5. （可选）关系密集资料开启知识图谱
6. 对固定话术（退货政策等）建 FAQ 库，与文档库一起挂到智能体

- [ ] 新人按「标准问题清单」自助问答通过率达标（团队自定，如 ≥80%）
- [ ] 错误答案有责任人修订分块或补文档的流程

## 场景三：群内 IM 问答

**背景**：同事不愿打开新系统，希望在已有群聊里 @ 机器人就能问。

**角色**：管理员配置渠道；群成员使用。

**建议步骤**：

1. 准备好智能体（已绑定知识库与模型）
2. 在「设置 → IM 集成」创建渠道，选择**企业微信 / 飞书 / 钉钉**之一
3. 按平台要求填写应用凭据并绑定智能体
4. 在测试群 @ 机器人提问，确认回复与出处
5. 再推广到正式群，并告知使用约定（如 /help、是否支持传文件入库等）

- [ ] 测试群提问有稳定回复
- [ ] 回复内容与 Web 端同一智能体一致或可接受
- [ ] 权限与可见知识范围符合约定

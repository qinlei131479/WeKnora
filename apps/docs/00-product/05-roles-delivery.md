# 角色与权限

说明工作空间内**谁能做什么**，以及启用前建议完成的检查项。权限实现细节见 [租户与认证](/03-features/01-tenant-auth)、[平台管理](/03-features/20-platform-admin)。

## 空间内角色

工作空间内常见四级角色（名称以界面为准）：

| 角色 | 能做什么（概括） | 典型人选 |
| --- | --- | --- |
| 所有者 Owner | 空间内最高权限，含成员与关键配置 | 空间负责人 |
| 管理员 Admin | 管理成员、模型、集成等 | 管理员、运维 |
| 贡献者 Contributor | 创建与维护知识库、智能体等 | 知识维护者 |
| 访客 Viewer | 只读提问与查看 | 业务用户 |

具体菜单是否可见，以当前空间角色与系统管理员身份为准。

## 功能边界提醒

开放能力请与 [功能说明](./02-capability-map) 一致。以下为**当前未开放**：

- 数据源自动同步、共享空间（组织）
- 命令行 / SDK、小程序 / 桌面 / 浏览器插件等未开放客户端
- 未在方案中写明的定制能力

## 启用前检查

### A. 环境与账号

- [ ] Web 控制台可访问（HTTPS / 域名按约定）
- [ ] 管理员账号可登录；测试业务账号已创建
- [ ] 工作空间划分符合组织方式

### B. 模型与基础配置

- [ ] 对话模型、向量模型可用（试连或试问通过）
- [ ] 必要密钥与存储位置已配置且不落在文档明文中传播

### C. 知识与问答

- [ ] 至少一个知识库完成上传与解析
- [ ] 智能体已绑定知识库，试问有合理回答
- [ ] 出处可打开并与问题相关
- [ ] （若需要）FAQ / Wiki / 图谱已启用并抽检

### D. 渠道（按需）

- [ ] IM：企微 / 飞书 / 钉钉中约定平台已连通
- [ ] 网页嵌入：测试页可用
- [ ] API：调用方持有约定权限的密钥

### E. 权限抽检

- [ ] 角色权限抽检通过（如访客不能改库）
- [ ] 关键问题清单通过率达到约定
- [ ] 遗留问题有责任人与计划

## 建议归档材料

1. 环境与账号说明（地址、角色、测试号）
2. 知识库与智能体清单
3. 试问问题表（问题 / 期望要点 / 是否通过 / 出处）
4. 渠道连通截图（IM / 嵌入，若有）
5. 未开放能力确认（避免范围蔓延）

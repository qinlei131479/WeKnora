# 产品概述

说明智能体中台 2.0 **是什么、能做什么、功能边界**。界面操作见 [操作指南](./04-user-guide)；机制与扩展见 [研发手册 · 总体架构](/02-architecture/01-overview)。

## 是什么

智能体中台 2.0 是一套**私有化部署的知识库问答系统**：把 PDF、Word、网页等资料收进知识库，团队成员可以直接提问，回答带可核对的出处。

核心价值：

- **有据可查**：回答引用知识库片段，降低「模型瞎编」风险
- **按资料作答**：先检索再生成，而不是只靠模型记忆
- **一套能力、多个入口**：Web 控制台、企业微信 / 飞书 / 钉钉、网页嵌入、API 等

## 核心流程

整条链路可以记成四步：

1. **收资料**：上传文件或粘贴网页地址
2. **读懂并建索引**：系统解析文档、切成可检索片段并建立索引
3. **提问检索**：按问题找出相关片段
4. **生成回答**：结合片段生成答案，并标注出处

## 能力摘要

| 能力 | 一句话 |
| --- | --- |
| 知识库与文档 | 建库、上传、解析、分块管理 |
| 智能体问答 | 快速问答 / 多步推理，绑定知识库 |
| Wiki | 从资料生成可浏览的百科结构 |
| 知识图谱 | 用实体关系增强「关系类」问题 |
| FAQ | 标准问答对，适合固定话术 |
| IM 机器人 | 企业微信、飞书、钉钉 |
| 网页嵌入 | 自有站点悬浮问答 |
| MCP | 对接外部工具 / 对外提供检索工具 |
| 评估 | 问答效果评测 |
| 权限与平台管理 | 工作空间、角色、系统管理员 |

完整表见 [功能说明](./02-capability-map)。机制说明见对应 [功能模块](/03-features/01-tenant-auth)。

## 功能边界

与控制台默认能力对齐，以下为**当前未开放**：

- 飞书云文档 / Notion / 语雀 / RSS 等**数据源自动同步**
- **共享空间（组织）**跨租户共享
- 命令行工具、Go SDK
- 微信小程序、桌面客户端、Chrome 插件、Claw Skill
- Lite 单机精简版形态

能力放开后，以产品说明与控制台实际入口为准。

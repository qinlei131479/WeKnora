# 报价单输出规范

模板结构已固化在本文件与 `../scripts/fill_quote.py` 的列定义、列宽和公式里，不再依赖外部 xlsx。本阶段以这里的列、用词和模拟行为金样。单价/税率/金额列**不要输出**。

用 `../scripts/fill_quote.py --input <rows.json> --output <交付文件.xlsx>` 生成。改列定义时必须同步改脚本。

## 列定义（12 列，禁止增删改序）

| 列 | 字段 | 必填 | 规则 |
| --- | --- | --- | --- |
| A | 一级功能 | 是 | 每行都写，不留合并空白 |
| B | 二级功能 | 是 | 每行都写 |
| C | 三级功能 | 是 | 依赖模块在名称后加 `*`，无空格 |
| D | 核心功能描述 | 是 | 1–2 句，角色+动作+目标；自动换行 |
| E | 产品时效 | 是 | 人天，数字 |
| F | 研发时效 | 是 | 人天，数字 |
| G | 交付时效 | 是 | 人天，数字 |
| H | 时效总计 | 是 | 公式 `=E{n}+F{n}+G{n}` |
| I | 功能匹配结果 | 是 | 仅三值：`已匹配` / `部分匹配` / `未匹配` |
| J | 匹配模块/功能 | 条件 | 已匹配、部分匹配必填；未匹配填 `-` |
| K | 匹配依据说明 | 条件 | 已匹配、部分匹配写理由；未匹配用固定句 |
| L | 匹配来源 | 条件 | 文件名或 `AI评估` |

「功能匹配结果」用模板用词 **未匹配**，不用规则原文的「不匹配」。

## 版式

- 表头加粗，底边框，垂直居中；D/J/K/L 自动换行
- 数据行垂直居中，底边框；行高随描述变高（约 43–58）
- 合计行：合并 `A{last}:D{last}`，A 写 `合计`，E–H 为 `=SUM(...)`，I–L 空
- 列宽对齐模板：A14.4 / B16.1 / C14.6 / D48 / E14.4 / F12 / G16.4 / I15.2 / J15.8 / K33.4 / L26.1
- 交付文件不要保留模板里的示例数据行，也不要保留第 6 行范例

## 匹配模块写法

`{标准或历史的一级功能} > {被复用的最小销售单元或三级功能}`

不要写成「二级 > 三级」，不要只写三级名。

## 匹配来源写法

| 情形 | 匹配来源 |
| --- | --- |
| 仅标准清单 | `标准化产品功能清单.xlsx（Sheet：数智全链运营）` |
| 标准 + 历史 | `标准化产品功能清单.xlsx + 重数传媒AI监播监控智能体功能清单.xlsx` |
| 仅历史 | `重数传媒AI监播监控智能体功能清单.xlsx` |
| P3 | `AI评估` |
| 标准命中但时效空、时效来自 AI | `标准化产品功能清单.xlsx（Sheet：数智全链运营）；时效：AI评估（标准清单时效字段为空）` |

Sheet 名必须是实际命中的那张。多文件用 ` + ` 连接。

## 依据句式（必须套用）

**已匹配：** `标准系统中{功能}已支持{能力}，可直接复用{界面/数据模型/流程}`

**部分匹配：** `标准/历史{功能}支持{已有能力}，但未覆盖{缺口}，需{改造动作}`

**未匹配（固定原文，不要改写）：** `未从标准产品功能清单和历史项目库中找到匹配项`

## 模拟金样（照这个粒度与语气写，不要照抄业务内容）

模板中 3 条业务行 + 1 条合计是正确输出形态；第 6 行只是未匹配字段范例。

### 金样 1 — 已匹配

| 字段 | 值 |
| --- | --- |
| 一级 / 二级 / 三级 | 监测配置与管理 / 监测机构管理 / 机构增删改查 |
| 核心功能描述 | 建立标准化机构信息库，支持单条录入，统一管理机构名称、介绍、网站 |
| 产品 / 研发 / 交付 / 总计 | 0.5 / 1 / 0.5 / 2 |
| 功能匹配结果 | 已匹配 |
| 匹配模块/功能 | CMS媒资管理系统 > CP/SP管理 |
| 匹配依据说明 | 标准系统中CP/SP管理已支持对CP/SP单位进行增删改查，可直接复用管理界面及底层数据模型 |
| 匹配来源 | 标准化产品功能清单.xlsx（Sheet：数智全链运营） |

对应标准事实：`CMS媒资管理系统 > 系统配置 > CP/SP管理`，描述含「具备增删改查」。金样把匹配模块写成 `一级 > 三级`，交付时保持该格式。

### 金样 2 — 部分匹配 + 依赖标记

| 字段 | 值 |
| --- | --- |
| 一级 / 二级 / 三级 | 监测配置与管理 / 监测任务运行能力 / 多AI平台对接* |
| 核心功能描述 | 支持对接五个主流AI平台实施监测，支持按站点、周期等自定义配置监测任务计划 |
| 产品 / 研发 / 交付 / 总计 | 2 / 8 / 3 / 13 |
| 功能匹配结果 | 部分匹配 |
| 匹配模块/功能 | 内容质量监测系统 > 监测任务配置 |
| 匹配依据说明 | 标准系统支持按平台、栏目、节目配置监测对象及执行方式，但未覆盖多外部AI平台对接能力，需新增接口适配层 |
| 匹配来源 | 标准化产品功能清单.xlsx + 湖北质量监测二期项目产品功能清单202604.xlsx |

要点：三级名带 `*`；依据同时写「已有配置能力」和「缺多外部 AI 平台，需新增适配层」；来源写标准 + 历史；时效明显高于金样 1（改造工时，不是复用工时）。

目录若无「湖北质量监测…」文件，只允许用已入库历史文件名，不要伪造该文件时效。

### 金样 3 — 部分匹配（历史底座 + 场景改造）

| 字段 | 值 |
| --- | --- |
| 一级 / 二级 / 三级 | AI对话问题挖掘 / AI对话问题挖掘 / 智能提问生成 |
| 核心功能描述 | 支持根据文本自动生成AI智能推荐热门提问条目 |
| 产品 / 研发 / 交付 / 总计 | 3 / 10 / 3 / 16 |
| 功能匹配结果 | 部分匹配 |
| 匹配模块/功能 | 质量监测系统 > 自然语言问答 |
| 匹配依据说明 | 附件的“自然语言问答”功能基于智能体实现文本交互和问题理解，可作为技术底座复用；但当前为故障监测场景，需改造为文本自动生成热门提问的业务逻辑 |
| 匹配来源 | 湖北质量监测二期项目产品功能清单202604.xlsx |

要点：承认可复用技术底座，同时写清场景与业务逻辑不同；改造类时效再高于金样 2。标准清单中对应单元实为 `内容质量监测系统 > 告警分析看板 > 自然语言问答`。

### 金样 4 — 合计

| 字段 | 值 |
| --- | --- |
| A:D | 合并，文案 `合计` |
| 产品 / 研发 / 交付 / 总计 | 5.5 / 19 / 6.5 / 31 |

验算：`0.5+2+3=5.5`，`1+8+10=19`，`0.5+3+3=6.5`，`2+13+16=31`，且 `5.5+19+6.5=31`。交付文件用 SUM 公式，数字必须与此勾稽方式一致。

### 金样 5 — 未匹配字段范例（不是业务行）

模板第 6 行：

| 功能匹配结果 | 匹配模块/功能 | 匹配依据说明 | 匹配来源 |
| --- | --- | --- | --- |
| 未匹配 | - | 未从标准产品功能清单和历史项目库中找到匹配项 | AI评估 |

真实未匹配业务行仍要填 A–H（含 P3 时效），I–L 用上表四字段。不要把第 6 行无功能、无时效的范例输出到交付文件。

## 时效量级对照（写行时自检）

| 类型 | 产品 | 研发 | 交付 | 总计 | 参照 |
| --- | --- | --- | --- | --- | --- |
| 标准 CRUD 直接复用 | 0.5 | 1 | 0.5 | 2 | 金样 1 |
| 有底座、需新增适配层 | 2 | 8 | 3 | 13 | 金样 2 |
| 有底座、需改业务逻辑 | 3 | 10 | 3 | 16 | 金样 3 |
| 历史原子任务（细粒度） | 0–0.5 | 0.5–2 | 0.2–0.5 | 0.2–2.7 | 重数传媒单行 |

报价行粒度接近金样 1–3 时，不要把历史单行 0.7 人天直接填成整模块。细清单按历史粒度逐行报价时，才用重数传媒量级。

## JSON 输入约定

```json
{
  "rows": [
    {
      "l1": "监测配置与管理",
      "l2": "监测机构管理",
      "l3": "机构增删改查",
      "desc": "建立标准化机构信息库，支持单条录入，统一管理机构名称、介绍、网站",
      "product": 0.5,
      "dev": 1,
      "delivery": 0.5,
      "match_result": "已匹配",
      "match_module": "CMS媒资管理系统 > CP/SP管理",
      "match_reason": "标准系统中CP/SP管理已支持对CP/SP单位进行增删改查，可直接复用管理界面及底层数据模型",
      "match_source": "标准化产品功能清单.xlsx（Sheet：数智全链运营）"
    }
  ]
}
```

`match_result` 只能是 `已匹配`、`部分匹配`、`未匹配`。

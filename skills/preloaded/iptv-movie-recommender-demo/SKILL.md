# 触发条件
- 用户请求推荐影片/电视剧，语句含**日期/节日/纪念日**（如"今天""儿童节""国庆""9月3日"）或**题材词**（如"抗战""动画""科幻"）。

# 输入参数（从对话中提取）
- query：用户找片语句（必填，如"今天是儿童节，请推荐几部影片"）
- date：显式日期（可选；缺省取当天，但节日名优先直接匹配，不依赖日期）

# 素材库（assets/）
| 文档 | 内容 | 用途 |
|---|---|---|
| catalog.md | 片单库：影片ID、名称、类型、年份、制作地区、题材标签、背景地域、关联人物/事件、简介 | 最终匹配与推荐理由元数据 |
| history_today.md | 全年156条：日期→节日/纪念日/事件 | "日期/今天"入口：确认当日节日 |
| topic_map.md | 节1：节日→建议题材；节2：题材词→候选标签 | 语义翻译层：把意图翻译成题材标签 |

# 执行流程
1. **意图解析**：从query提取两类入口信号——
   - 节日/日期信号：节日名（儿童节/国庆/端午…）或日期（今天/9月3日/10月1日…）
   - 题材信号：题材词（抗战/动画/科幻/爱情…）
2. **入口一（日期/节日）**：
   - 提到节日名 → 直接在 topic_map.md 节1匹配，取建议题材标签。
   - 只提到"今天/日期" → 查 history_today.md 得当日节日/纪念日 → 再去 topic_map.md 节1转题材；当日无收录 → 降级通用推荐。
3. **入口二（题材）**：题材词 → topic_map.md 节2扩展候选标签集。
4. **跨表匹配**：用题材标签集在 catalog.md 逐行匹配（标签包含任一命中即算命中），命中多标签者优先。
5. **输出TopN**：取命中影片 Top3（电影+电视剧均可）。
6. **生成理由**：模板拼接——节日依据 + 影片元数据佐证（年份/制作地区/背景地域/关联人物/简介），体现"片单 × 数据"联动。

# 推荐理由模板
- 节日型："今天是【节日】（【日期】），为您推荐【题材】影片《【名称】》——【年份】年出品，【简介】。相关：【关联人物/事件】，背景：【背景地域】"
- 题材型："【题材】题材影片《【名称】》，【年份】年【制作地区】出品，讲述【简介】。相关：【关联人物/事件】"
- 降级型："今日无特殊节日，为您推荐【题材】/经典影片如下"

# 演示示例（可直接演示）
| 用户语句 | 匹配路径 |
|---|---|
| 今天是儿童节，请推荐几部影片？ | 节日名"儿童节" → 题材[儿童、动画、亲子] → 熊出没/哪吒/大圣归来/大头儿子 |
| 推荐抗战的影片 | 题材词"抗战" → 标签[抗战、军事、战争、历史] → 四渡赤水/血战台儿庄/亮剑/小兵张嘎/太行山上 |
| 今天是国庆，推荐影片 | 节日名"国庆" → 题材[主旋律、历史、爱国] → 建国大业/我和我的祖国/开国大典/长津湖 |
| 今天有什么好看的？（无节日命中） | 取当天日期 → history_today 查节日 → 无则降级通用推荐 |

# 安全与边界
- 历史/军事内容仅做正向文化关联，不做政治评价。
- 国家公祭日等纪念日仅作"勿忘历史"题材关联，描述保持中性。
- 演示数据为示例，接入真实片单时替换 catalog.md 即可，字段格式保持不变。

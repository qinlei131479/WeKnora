# 项目经理软技能（通用知识）

## 一、领导力 vs 管理
- **管理**：把事情做对（计划、组织、控制，关注流程）。
- **领导力**：做对的事情（愿景、方向、激励，关注人）。
- 成熟项目经理两者兼备：用管理保证交付，用领导力凝聚团队。

## 二、沟通
- **原则**：先规划沟通（5W：谁/何时/何地/何事/为何），再执行沟通，最后监督效果。
- **主动倾听**：不打断、复述确认、追问澄清，比"说"更重要。
- **向上管理**：给上级"结论先行 + 选项 + 建议"，管理期望、提前暴露风险，不报喜不报忧。
- **跨层级适配**：对管理层讲结果与风险，对团队讲任务与意义。

## 三、冲突管理（五种模式，按场景选择）
| 模式 | 适用场景 |
|---|---|
| 撤退/回避 | 冲突琐碎、需要冷却时间 |
| 缓和/包容 | 关系重要、损失可接受 |
| 妥协 | 双方势均力敌、时间紧迫 |
| 强迫/命令 | 紧急、必须快速决断 |
| 合作/解决 | 复杂问题、需要双赢（最理想但成本高） |

> 提示：先区分"任务冲突"（对事，有益）与"关系冲突"（对人，有害）。任务冲突可激发讨论，关系冲突需及时干预。

## 四、谈判（原则性谈判）
- 对事不对人；聚焦利益而非立场；创造双赢选项；用客观标准（数据/基准）说话。
- 应用场景：资源争取、范围谈判、供应商合同、需求优先级。

## 五、决策
- 常见方法：独裁（信息全/时间紧）、咨询后决策、多数投票（需防分裂）、一致同意（重大但慢）。
- 高质量决策 = 信息充分 + 干系人参与 + 记录决策依据（决策日志/ADR）。

## 六、团队激励
- **马斯洛需求层次**：生理 → 安全 → 社交 → 尊重 → 自我实现，按需激励。
- **赫兹伯格双因素**：保健因素（薪资/环境）只能防不满，激励因素（成就/认可/成长）才带来满意。
- **McGregor X-Y 理论**：X 假设人懒惰需控制；Y 假设人自主愿担责。现代实践以 Y 为主（授权、赋能）。
- 实操：及时认可、公开表扬、给成长机会、透明目标与反馈。

## 七、干系人期望管理
- 先识别（谁影响/被影响），再分类（权力-利益），规划参与策略，持续监督满意度。
- 关键：管理期望 = 提前对齐 + 透明沟通 + 兑现承诺，比"满足所有要求"更可行。

## 八、个人效能
- 时间管理（优先级矩阵/四象限：重要紧急 > 重要不紧急 > 紧急不重要 > 不重要不紧急）。
- 复盘习惯：项目结束时做经验教训总结，沉淀到组织知识库。

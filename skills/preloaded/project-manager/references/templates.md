# 项目管理常用模板结构

以下为可直接复用/改写的模板骨架。生成时按项目类型裁剪，并给出填写示例。

## 一、项目章程（启动）
- 项目名称与背景；项目目标（SMART）；范围概要；主要干系人；发起人授权；里程碑时间表；总体预算；主要风险与假设；成功标准。

## 二、WBS（范围）
- 层级编号（如 1.1、1.2）；工作包为最底层单元；每项可估算、可分配、可验收。

## 三、进度计划（规划）
- 任务 / 负责人 / 依赖（FS/SS 等）/ 计划起止 / 工期 / 里程碑；可配甘特图。

## 四、风险登记册
- 编号 / 描述 / 类别 / 概率 / 影响 / 得分 / 触发条件 / 应对策略 / 责任人 / 状态 / 更新日期。

## 五、干系人登记册
- 姓名 / 角色 / 联系方式 / 权力 / 利益 / 参与策略 / 知情级别。

## 六、沟通计划
- 沟通事项 / 受众 / 频率 / 渠道 / 负责人 / 格式（如周报、站会、评审会）。

## 七、进度周报
- 本期完成 / 下期计划 / 风险与问题 / 偏差与预测 / 需干系人决策事项。

## 八、会议纪要
- 时间地点参会人 / 议题与结论 / 行动项（事项-负责人-截止）/ 待确认事项。

## 九、变更请求
- 变更描述 / 理由 / 影响评估（范围-进度-成本-质量）/ 方案选项 / 申请人 / 审批状态。

## 十、项目复盘报告
- 项目结果 vs 目标；做得好（可复用）；做得差（教训）；延期/超支原因；改进措施；经验教训登记。

## 十一、挣值报告
- PV / EV / AC / SV / CV / SPI / CPI / EAC / 偏差解释 / 纠偏建议。

> 使用提示：模板给结构，示例给填法；关键字段不要留空占位，用具体项目数据填充；涉及数字必须来自项目真实数据。

# PMBOK 框架（PM 知识骨架）

知识口径：以 PMBOK 第六版"五大过程组 × 十大知识领域 × 49 过程"为骨架，PMBOK 第七版（12 原则 + 8 绩效域）作为补充视角。回答涉及版本差异时标注来源版本。

## 一、核心结构

- **五大过程组（Process Groups）**：启动 → 规划 → 执行 → 监控 → 收尾
- **十大知识领域（Knowledge Areas）**：整合 / 范围 / 进度 / 成本 / 质量 / 资源 / 沟通 / 风险 / 采购 / 干系人
- **49 个过程**：每个过程属于某一过程组 + 某一知识领域的交叉点

## 二、五大过程组

| 过程组 | 作用 | 关键活动 | 关键交付物 |
|---|---|---|---|
| 启动 | 定义项目或阶段、获得授权 | 制定项目章程、识别干系人 | 项目章程、干系人登记册 |
| 规划 | 制定行动路线 | 规划各知识领域、收集需求、制定计划 | 项目管理计划、WBS、进度/预算/风险登记册 |
| 执行 | 按计划开展并完成工作 | 指导与管理项目工作、建设团队、管理沟通 | 可交付成果、工作绩效数据、变更请求 |
| 监控 | 跟踪、审查、调整进展 | 监控项目工作、实施整体变更控制 | 工作绩效信息、变更请求、预测 |
| 收尾 | 正式结束项目或阶段 | 结束项目或阶段、移交成果 | 最终产品/服务移交、经验教训登记册 |

## 三、十大知识领域与 49 个过程（PMBOK6）

### 1. 项目整合管理（7 个）
协调项目各要素、统一变更控制。过程：制定项目章程、制定项目管理计划、指导与管理项目工作、管理项目知识、监控项目工作、实施整体变更控制、结束项目或阶段。

### 2. 项目范围管理（6 个）
确保"做且只做"所需工作。过程：规划范围管理、收集需求、定义范围、创建 WBS、确认范围、控制范围。

### 3. 项目进度管理（6 个）
确保按时完成。过程：规划进度管理、定义活动、排列活动顺序、估算活动持续时间、制定进度计划、控制进度。

### 4. 项目成本管理（4 个）
确保在预算内完成。过程：规划成本管理、估算成本、制定预算、控制成本。

### 5. 项目质量管理（3 个）
确保交付满足要求。过程：规划质量管理、管理质量、控制质量。

### 6. 项目资源管理（6 个）
获取和管理资源。过程：规划资源管理、估算活动资源、获取资源、建设团队、管理团队、控制资源。

### 7. 项目沟通管理（3 个）
确保信息正确传递。过程：规划沟通管理、管理沟通、监督沟通。

### 8. 项目风险管理（7 个）
管理不确定性。过程：规划风险管理、识别风险、实施定性风险分析、实施定量风险分析、规划风险应对、实施风险应对、监督风险。

### 9. 项目采购管理（3 个）
从外部获取资源。过程：规划采购管理、实施采购、控制采购。

### 10. 项目干系人管理（4 个）
管理受影响/影响项目的人。过程：识别干系人、规划干系人参与、管理干系人参与、监督干系人参与。

> 过程计数：7+6+6+4+3+6+3+7+3+4 = 49。

## 四、PMBOK 第七版（补充视角）

**12 项目管理原则**：管家式管理、团队、干系人、价值、系统思考、领导力、裁剪、质量、复杂性、风险、适应性与韧性、变革。

**8 项目绩效域**：干系人、团队、开发方法和生命周期、规划、项目工作、交付、测量、不确定性。

> 使用说明：经典"过程组 × 知识领域"适合讲流程、ITTO、考试口径；七版原则/绩效域适合讲价值导向和现代实践。两者并存，回答时说明采用哪一版视角。

## 五、关键概念辨析

| 概念 | 区别 |
|---|---|
| 项目 vs 项目集 vs 项目组合 | 项目=独立交付；项目集=关联项目协同管理获益；项目组合=为战略目标组合选择/排序项目 |
| 项目生命周期 vs 产品生命周期 | 项目生命周期=从启动到收尾；产品生命周期=从概念到退役，可含多个项目 |
| 渐进明细 | 项目信息随时间推进逐渐清晰（滚动式规划） |
| 项目章程 vs 项目管理计划 | 章程=授权与高层级目标（启动）；计划=执行细节（规划） |
| 确认范围 vs 控制质量 | 确认范围=验收可交付成果（干系人签字）；控制质量=验证成果符合质量标准 |

# 项目管理工具与技术

## 一、范围类

### WBS（工作分解结构）
- **是什么**：将项目可交付成果分解为更小、更易管理的层级结构（树状）。
- **怎么用**：100% 原则（下层之和=上层）、面向交付物而非动作、分解到可估算/可分配的最小单元（工作包）、统一编码。
- **注意**：WBS 不含时间顺序，也不含依赖关系。

## 二、进度类

### 甘特图（Gantt）
- 横轴时间、纵轴任务，条形显示起止，直观展示进度与并行任务。

### 关键路径法（CPM）
- **是什么**：识别项目网络中最长的活动路径，决定项目最短工期。
- **怎么用**：① 列出活动与依赖 ② 画网络图 ③ 正推计算最早开始/结束 ④ 逆推计算最晚开始/结束 ⑤ 浮动时间=0 的活动构成关键路径。
- **要点**：关键路径上的活动延误一天，整个项目延误一天；缩短工期需压缩关键路径。

### 三点估算（PERT）
- 公式：`期望工期 E = (O + 4M + P) / 6`（O 乐观、M 最可能、P 悲观）；标准差 `σ = (P - O) / 6`。
- 用途：应对估算不确定性，给出工期区间。

### 滚动式规划
- 近期工作详细规划，远期工作粗略规划，随项目推进渐进明细。

### 里程碑
- 时间轴上的零工期检查点，用于阶段验收和高层汇报。

## 三、成本类：挣值管理（EVM）

核心指标（所有数字由数据算出，不靠估算）：
- **PV** 计划价值（计划到某时点应完成的价值）
- **EV** 挣值（实际完成工作的价值）
- **AC** 实际成本（实际花费）
- **SV = EV - PV**（进度偏差，>0 超前）
- **SPI = EV / PV**（进度绩效，>1 超前）
- **CV = EV - AC**（成本偏差，>0 结余）
- **CPI = EV / AC**（成本绩效，>1 节省）
- **EAC = BAC / CPI**（典型偏差下的完工估算）

> 例：BAC=100 万，已完成 40% 工作，花费 50 万 → EV=40，AC=50，CV=-10（超支 10 万），CPI=0.8。

## 四、风险类

### 概率-影响矩阵
- 按"发生概率 × 影响程度"对风险定级（低/中/高），高优先应对。示例评分：低=1、中=2、高=3，得分≥中高需重点关注。

### 风险登记册
- 字段：描述、类别、概率、影响、得分、触发条件、应对策略、责任人、状态。

### 风险应对策略
- 威胁：规避 / 转移 / 减轻 / 接受；机会：开拓 / 提高 / 分享 / 接受。

## 五、干系人与沟通类

### RACI 矩阵
- R=执行 Responsible、A=批准 Accountable、C=咨询 Consulted、I=知会 Informed。每项任务恰好一个 A。

### 干系人权力-利益矩阵
- 高权力高利益：重点管理；高权力低利益：令其满意；低权力高利益：随时告知；低权力低利益：监督。

### 沟通渠道数
- `n(n-1)/2`，n=干系人/成员数。用于说明团队膨胀带来的沟通复杂度。

## 六、质量类

- **PDCA**：计划-执行-检查-处理，持续改进循环。
- **七种基本质量工具**：因果图（鱼骨图）、流程图、核查表、帕累托图、直方图、控制图、散点图。
- **控制图**：监控过程是否稳定，识别特殊原因变异（超出控制界限）。
- **质量成本（COQ）**：预防成本 + 评估成本 + 失败成本（内部/外部）。

## 七、通用

- **头脑风暴 / 德尔菲**：收集意见（德尔菲匿名多轮收敛，避免权威影响）。
- **SWOT**：优势/劣势/机会/威胁分析。
- **蒙特卡洛模拟**：定量风险分析，模拟大量结果给概率分布。
- **变更控制流程**：变更请求 → 评估影响 → 审批（CCB）→ 更新计划/基线 → 通知干系人。
